# 产能画像 - Capacity Profile

## 基本定位
- 自媒体创作者，AI赛道，定位AI初学者
- 同时运营商标注册代理公司，需要引流

## 可生产内容形式

| 形式 | 熟练度 | 说明 |
|---|---|---|
| 图文 | 高 | 公众号/小红书/知乎，熟练 |
| 视频 | 高 | 剪映/DaVinci，熟练 |
| 测评/教程 | 中 | 需要实操演示 |
| 深度分析 | 中 | 需要大量研究支撑 |

## 内容约束

### 能做
- AI工具测评和教程（图文+视频）
- AI经验干货分享（图文）
- 避坑指南（图文+视频）
- AI视频剪辑包装（视频）
- 提示词工程教程（图文）
- Agent/Skill 实践分享（图文+视频）
- 副业变现思路（图文+视频）
- 自媒体运营策略（图文）
- 商标/IP/创业知识科普（AIGC剧情向视频）

### 不能做/不想做
- 真人出镜口播（不想天天拍）
- 需要大量实拍的内容
- 需要专业摄影设备的内容
- 纯理论无实操的学术内容

### 偏好方向
- AIGC剧情向内容（用于商标代理引流，高自动化）
- 实操性强的内容（用户能跟着做）
- 争议性/冲突性选题（容易传播）
- 数据驱动型选题（有说服力）

## 工具能力
- 视频剪辑：剪映Pro、DaVinci Resolve
- AI工具：TRAE、ChatGPT、DeepSeek、Midjourney等
- 平台：公众号、小红书、知乎、抖音、B站

## 目标受众
- AI初学者（主力）
- 想用AI变现的个人
- 对AI工具感兴趣的小白
- 需要商标注册服务的小微企业主（副线）
